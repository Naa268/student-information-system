# student management system
A basic python program for managing students detail.
----
### Features
The program takes the following inputs from user 
* Full Name
* Student ID
* Programme
* Level
* Age
* Favourite Programming Language

Then, using string concatenation (not just printing the raw inputs), the program must generate two new pieces of information from what the user typed:

A Student Username — built by combining part of their name with their Student ID (e.g. first 3 letters of their name + Student ID).
A Student Email — built by combining their generated username with a fixed domain, e.g. username + "@st.ug.edu.gh".
Finally, the program builds its own border/divider line using concatenation (e.g. joining "=" characters together into one string variable) rather than typing out ======== directly wherever it's needed.
